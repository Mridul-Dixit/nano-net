# nano-Net: A Minimal Neural Network 

<p>Nano-Net is a lightweight neural network library implemented from scratch in Python. This project is a hands-on approach to understanding the inner workings of deep learning by building essential components such as tensors, gradients, and layers. It is designed for learning purposes and provides a foundation for implementing neural networks for small-scale projects.</p>

<b>Inspired by Andrej Karpathy's [micrograd](https://github.com/karpathy/micrograd): Nano-Net draws inspiration from the simplicity and educational value of micrograd, expanding upon it with additional features and flexibility.

</b>
